# MHR. simulator

モンスターハンターワイルズ用のアーティア厳選ツール＋装備スキルシミュレータ。
HTML1枚で動くので、サーバーもビルドも不要です。

## 使い方

- **アーティア工房** … 武器種と属性を選ぶと、厳選テーブル・使える復元ボーナス・仕上がりの攻撃力/会心率が出ます。個体を記録に残せます。
- **強化テーブル** … スキルとは別枠の「強化（復元ボーナス）」が、何回目にどう並ぶかを記録します。5枠分を入れると右に個数が出ます。「攻撃力2個以上・切れ味1個以上」のように内訳を指定すると、当たりの回が光ります。Excelからの貼り付け取り込みに対応。
- **未来視テーブル** … 生産回数ごとのシリーズ／グループスキルを表で管理します。武器種を複数選ぶと横に並びます。当たりにするスキルを選ぶと、該当マスが光ります。
- **装備シミュレータ** … 武器・防具・護石・装飾品からスキルLvを集計します。

## ID（記録の引き出し）

画面右上の **ID** で、記録の引き出しを分けられます。未来視テーブル・厳選記録・装備構成が、IDごとに別々に保存されます。

| ボタン | すること |
| --- | --- |
| 新規 | まっさらなIDを作ります。今のIDは残ります |
| 名前 | 選んでいるIDの名前を変えます |
| 複製 | 今のIDをまるごとコピーして、別のIDにします |
| 削除 | 選んでいるIDを消します（元に戻せません。IDが1つのときは押せません） |
| 書出 | 選んでいるIDをまるごとJSONに保存します |
| 読込 | 書き出したJSONを、**新しいID**として読み込みます（今あるIDは消えません） |

入力内容はブラウザに自動保存されます。保存先はその端末のそのブラウザの中なので、スマホとPCで同じ記録を見たいときは「書出」でJSONを保存し、移動先で「読込」してください。

## 公開のしかた（GitHub Pages）

1. このリポジトリの Settings → Pages を開く
2. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
3. 1〜2分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が開きます

## データの直し方

`index.html` の上のほうにデータがまとまっています。ゲーム側のアップデートで数値が変わったら、ここだけ直せば動きます。

| 場所 | 中身 |
| --- | --- |
| `ARTIAN` | アーティアの基礎値・テーブル判定・復元ボーナスの上限・武器種ごとの弾／ビン／砲撃 |
| `SERIES_SKILLS` | シリーズスキル（2部位・4部位の効果） |
| `GROUP_SKILLS` | グループスキル（3部位の効果） |
| `DATA.armors` `DATA.decos` `DATA.charms` | 防具・装飾品・護石（※まだサンプルです） |

## 出典

アーティアのテーブルと復元ボーナスの仕様は、有志の検証記事を参照しました。実機と食い違う場合は `ARTIAN` の値を直してください。
